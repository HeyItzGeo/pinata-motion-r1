---

## What this tool does

This software reads and writes animation data in a proprietary format used by *Viva Piñata: Trouble in Paradise*. It is intended for interoperability and research purposes — allowing users to modify animation data in their own locally owned copy of the game.

## Third-party components

This repository's Python code reimplements format algorithms that were originally reverse-engineered by others. Those projects are credited in [`CREDITS.md`](CREDITS.md).
